# Pokémon cries

Put one sound file per Pokémon in this folder, named with the Pokémon's ID from
Admin → Content → Pokémon (lower case), for example:

    bulbasaur.mp3
    charmander.mp3
    pikachu.mp3

The file type is set in Admin → Game settings → Sound & music → Cry file type (mp3 by default).
Pokémon without a file use a cry the game makes up for that species.

Only add sound files you have the right to use and publish: this folder is part of the public website.
